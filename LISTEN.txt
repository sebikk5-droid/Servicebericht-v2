Servicebericht – dwa repozytoria

1) Aplikacja PUBLIC (github.io):
   https://sebikk5-droid.github.io/Servicebericht-v2/v2.html
   Repo: Servicebericht-v2
   Tu NIE ma companies.json / e-maili / maszyn.

2) Listy PRIVATE:
   Repo: Servicebericht-listen
   Pliki: companies.json, customer-emails.json, customer-machines.json

Wgrywanie listy firm (companies.json):

- Format apki: firma, tel, email, adres ("ulica, PLZ miasto"), notatki ("290km, 4")
- Gotowy plik: companies.json z konwersji Excela/JSON (270 firm)
- GitHub → Servicebericht-listen → Add file → Upload files
  Wgraj: companies.json
  (opcjonalnie customer-emails.json i customer-machines.json jako { } jeśli jeszcze nie ma)
- W apce: GitHub an · Token (Contents: Read and write na Servicebericht-listen)
- Po wgraniu: w apce odśwież / Pull listę firm

Uwagi konwersji:
- 2× „Müller” → „Müller (Lichte)” i „Müller (Gefrees)” (apeka rozróżnia po nazwie)
- 8 firm bez km/czasu → puste notatki (trasa przy zapisie w apce)
- e-maile / maszyny nie były w Excelu → zostają puste (aktualna lista prywatna
  potrzebna tylko jeśli chcesz zachować stare e-maile i maszyny)
