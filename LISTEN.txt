Wgrywanie listy firm (companies.json):

- Format apki: firma, tel, email, adres ("ulica, PLZ miasto"), notatki ("290km, 4")
- Gotowy plik: companies.json z konwersji Excela/JSON (270 firm)
- GitHub → Servicebericht-listen → Add file → Upload files
  Wgraj: companies.json
  (opcjonalnie customer-emails.json i customer-machines.json jako { } jeśli jeszcze nie ma)
- W apce: GitHub an · Token (Contents: Read and write na Servicebericht-listen)
- Po wgraniu: w apce odśwież / Pull listę firm
